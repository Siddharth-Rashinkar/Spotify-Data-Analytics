# 🎵 Spotify Music Analytics Dashboard

## 📌 Project Overview
This project is an interactive Spotify Music Analytics Dashboard built using Power BI.  
The dashboard provides insights into songs, artists, genres, popularity, and music trends using Spotify dataset analysis.


## Features
- KPI Cards for:
  - Total Songs
  - Total Artists
  - Average Popularity
  - Average Tempo

- Interactive Visualizations:
  - Top 8 Popular Songs
  - Top Artists
  - Top Genres

- Dynamic Filters:
  - Genre Filter
  - Artist Filter
  - Explicit Content Filter

- Spotify-inspired dark theme dashboard design



## Tools & Technologies Used
- Power BI
- Power Query
- Data Cleaning
- Data Visualization
